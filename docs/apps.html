Per-App Snippets

Choose which apps a snippet or group works in. The same abbreviation can even type different text in different apps.

Three levels of rules

Shorthand Expander™ checks, in order, and uses the first rule that applies:

The default for all groups

  1. Open Settings ▸ Expansion.
  2. In Expand snippet groups in, choose All applications, All applications except… or Only these applications….
  3. For the last two, click Add Application… and pick apps. Remove one with its minus button.

Example: exclude your code editor so abbreviations never fire while you program.

A whole group

  1. Select the group in the sidebar.
  2. Under Expansion, set Expand in to one of: Default (from Preferences), All Applications, All Applications, Except…, Only These Applications… or No Applications (Disabled).
  3. Add apps with Add Application… if needed.

Example: a group of terminal commands set to Only These Applications… with Terminal.

A single snippet

  1. Select the snippet.
  2. Set Expand in: to Same as group, All Applications, All Applications, Except…, Only These Applications… or No Applications.
  3. Add apps with Add Application….

Same abbreviation, different apps

When more than one snippet has the same abbreviation, the one aimed at the current app wins: a snippet set to “Only These Applications…” beats one set to “All Applications, Except…,” which beats a general one. Snippet rules count before group rules.

Example: two snippets with the abbreviation ;sig:

SnippetExpand in:Result
“Best, John” (casual)Same as group (all apps)Used everywhere else
“Kind regards, John Appleseed, Example Ltd.” (formal)Only These Applications… MailUsed in Mail

Snippet suggestions follow the default in Settings ▸ Expansion ▸ Expand snippet groups in: phrases typed in excluded apps are never counted.
