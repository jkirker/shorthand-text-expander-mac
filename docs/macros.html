You don’t have to remember these. In the snippet editor, click the Insert menu (above the text, on the right) and pick a code. Its submenus are Date, Time, Date/Time Math, Fill-ins, Snippet, Key, Clipboard, Calculation, Condition, AI ✨, Cursor, Delimiter and Percent Sign (%).

Fill-ins

Fill-ins open a small window where you type or choose values before the snippet is inserted. See Fill-ins for a walkthrough.

CodeWhat it does
%filltext:name=Name:default=Sam:width=20%A single-line text field. All settings are optional.
%fillarea:name=Notes:default=:width=30:height=5%A multi-line text box. width and height are in characters and lines.
%fillpopup:name=Size:Small:default=Medium:Large%A pop-up menu. Options are separated by colons; default= marks the option chosen at first. Without it, the first option is chosen.
%fillpart:name=PS:default=yes%…%fillpartend%An optional section with a checkbox. The text between the two codes is included only when the box is ticked. default=yes (or true or 1) ticks it at first.
%filltop%Opens the fill-in window at the top centre of the screen instead of near the text cursor.

Settings inside a fill-in: name=, default=, width= (not for pop-ups) and height= (multi-line boxes only). Fields with the same name share one value, so you type it once.

Date and time

Names of months, weekdays and AM/PM follow your Mac’s language and region settings. Examples are for Monday, 5 January 2026 at 2:05:07 PM in New York.

CodeShowsExample
%YYear, four digits2026
%yYear, two digits26
%BMonth nameJanuary
%bShort month nameJan
%mMonth number, two digits01
%1mMonth number, no leading zero1
%AWeekday nameMonday
%aShort weekday nameMon
%dDay of the month, two digits05
%eDay of the month, no leading zero5
%jDay of the year, three digits005
%HHour, 24-hour clock, two digits14
%1HHour, 24-hour clock, no leading zero14
%IHour, 12-hour clock, two digits02
%1IHour, 12-hour clock, no leading zero2
%MMinute, two digits05
%1MMinute, no leading zero5
%SSecond, two digits07
%1SSecond, no leading zero7
%pAM or PMPM
%zOffset from GMT-0500
%ZTime zone abbreviationEST
%date:yyyy-MM-dd%Any custom format, using Unicode date patterns2026-01-05

Capital and small letters mean different things: %1m is the month, %1M is the minute. %d pads with a zero, %e doesn’t.

Date and time math

Put %@, a plus or minus sign, a number and a unit before your date codes. Every date code after it uses the shifted date.

CodeShifts the date by
%@+1YYears
%@+1MMonths (capital M)
%@+15DDays
%@-1DDays back (yesterday)
%@+2hHours
%@+30mMinutes (small m)
%@+45sSeconds

More examples on Dates & Times.

Clipboard and other snippets

CodeWhat it does
%clipboardInserts the text currently on the clipboard.
%snippet:sig%Inserts another snippet by its abbreviation (here sig). Snippets can include snippets up to 8 levels deep. If no snippet has that abbreviation, nothing is inserted.

Calculations, conditions and AI

CodeWhat it does
%calc:{qty}*{price}:2%Works out a sum. :2 at the end means two decimal places. See Calculations & Conditions.
%if:{field}%…%else%…%endif%Includes text only when a condition is true. %else% is optional.
%ai:Write a polite reply to: {clipboard}%AI writes this part when the snippet expands. Needs an AI provider (Setting Up AI).

{name} means “the value of the fill-in called name”, and {clipboard} means the clipboard text. These references work only inside %calc, %if and %ai, so curly braces in ordinary text (CSS, code) are left alone.

Keys

%key:name% presses a key while the snippet is being typed, for example to move between fields in a web form.

CodePresses
%key:tab%Tab
%key:return%Return
%key:enter%Enter
%key:esc% or %key:escape%Escape
%key:space%Space
%key:backspace%Delete (backwards)
%key:delete% or %key:forwarddelete%Forward delete
%key:up% / %key:uparrow%Up arrow
%key:down% / %key:downarrow%Down arrow
%key:left% / %key:leftarrow%Left arrow
%key:right% / %key:rightarrow%Right arrow
%key:home%, %key:end%Home, End
%key:pageup%, %key:pagedown%Page Up, Page Down

Key names are not case-sensitive. An unknown key name is left in the text as typed.

Cursor and selection

CodeWhat it does
%|Puts the text cursor here after expanding.
%\Used after %|: selects the text between the two codes.
%<Moves the cursor one place left after expanding.
%>Moves the cursor one place right.
%^Moves the cursor up one line.
%vMoves the cursor down one line.

Example: <b>%|</b> types <b></b> and leaves the cursor between the tags.

Delimiter and percent sign

CodeWhat it does
%+Keep the delimiter (the space, Return, etc. you typed after the abbreviation), whatever your setting.
%-Drop the delimiter, whatever your setting.
%%A literal percent sign.

See Delimiters for what a delimiter is.

Rules worth knowing

  • A code runs to the next %. So a prompt, condition, field name or default can’t contain a % sign, and fill-in settings can’t contain a colon.
  • Write %% for a real percent sign, e.g. Save 20%% today.
  • Anything that isn’t a known code is left exactly as written, so 100% sure still types “100% sure”.
  • Script snippets (AppleScript, shell, JavaScript) don’t use these codes; their output is inserted as-is. See Script Snippets.
